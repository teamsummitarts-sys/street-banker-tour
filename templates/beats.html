    API integrations

    Not built. This tab is here so the plan is on the record, not because there is something behind it. Nothing below works today, and none of it is scheduled — when one of these ships it will appear here doing its actual job.

    • Beat store syncPush a registered beat, its tags and its licence tiers to a storefront, and pull back sales so the cleared list keeps itself.
    • Fingerprint monitoringHand a vendor (ACRCloud, Audible Magic, Pex) the audio and receive matches as usage cases. This is a paid account and a signed agreement, not a switch.
    • Split sheets to distributionSend the agreed producer split with the release so it does not get retyped at the distributor.
    • WebhooksFire on licence signed, exclusive sold, and usage case opened, so a producer's own tooling can react.

    Fingerprint monitoring is the only one with a working path in the codebase today: set the vendor's keys and the state line at the top of this page turns green on its own.
