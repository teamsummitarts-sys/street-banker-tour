# ElevenLabs sound generation — V2 test build

Noise Lab can now request a new 5, 8 or 10 second MP3 from ElevenLabs Sound Effects v2. This is separate from the existing OpenAI effect-settings operation. The generated candidate never replaces the current source automatically. Choose Load generated audio, then Play; existing macros, clean comparison, A/B settings comparison and WAV rendering use the same protected DSP graph.

Only the new description, duration and loop preference go to ElevenLabs. Imported audio is not sent. The application holds generated bytes in memory, not in a cloud audio library. Download original provides the provider MP3; WAV export renders current B processing. Private patches still save settings only. Full session recall, audio-source Undo and transfer to Song Builder are outside this build. Existing WAV import remains WAV-only; the original MP3 can be used in an audio editor or Song Builder.

The host reuses ELEVENLABS_API_KEY. NOISE_LAB_SFX_ENABLED defaults to 1 but requires the key and Noise Lab's mounted persistent-storage check. Setting it to 0 disables new requests. Capability checks distinguish key missing, disabled, storage unavailable and configured; configured is not proof of provider entitlement or credits.

POST /noise-lab/api/sound-effects is account-gated, same-origin/CSRF protected, accepts only a bounded JSON body, and uses a fixed provider endpoint with redirects prohibited. No retries. Durable reservations allow 20 attempts/account and 100/service for this test release, including failures and cancellations. A duplicate request ID is rejected, not resubmitted. The additive noise_lab_sfx_requests table stores only owner, request ID, start time, completion marker and duration. It survives restart and is included in the existing host SQLite backup. Two concurrent requests/service, one/account, ten-second cooldown, and stale concurrency lease expiry after 180 seconds. These ceilings are independent of Song Builder's existing job quotas and are not a shared monetary budget.

Server responses are bounded to 2 MiB; browser decoding checks duration, channel count and finite PCM. Decoding failures, cancelled loads, newer source selections and newer edits retain the previous source. Generating a candidate does not start playback. A loaded candidate follows the existing output ceiling and export bounds. A request already submitted may still consume credits after cancellation or a client disconnect.

Provider contract: https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert
Fixed MP3 output avoids assuming an account has access to higher-tier PCM formats. API keys may require Sound Effects permission separately from Music. Commercial use and account entitlements must follow the user's ElevenLabs plan; this integration does not change that plan.

Verification includes real SQLite reservation/restart/concurrency tests, request validation, provider-response failures, browser-controller cancellation/account-scope checks, and engine decode/retention/WAV checks. Real provider availability and physical iPhone decoding need a live request; no synthetic test establishes premium sound quality.
