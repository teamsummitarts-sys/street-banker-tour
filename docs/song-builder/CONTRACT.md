# Song Builder implementation contract

Portable Flask blueprint and native ES modules; initial V2 integration only.
Source inspected at upstream commit `34257fb34282d889b9fd5b86292c014dfc811338`.

## Ownership

- Backend owns `song_builder/*.py` and `tests/test_song_builder*.py` (except host test).
- Audio/core owns `song_builder/static/core/*.mjs` and `tests/song_builder/core*.mjs`.
- Coordinator owns template, UI, host registration, harness, docs and integration.

## Project JSON v1

Exact root keys: `schemaVersion:1`, `id` (UUID), `title` (1–120 chars),
`tempo` (40–240 target BPM), `key` (0–24 chars), `sections`, `tracks`, `clips`.

Section: `{id,name,duration,lyrics,direction,locked}`. UUID IDs; name 1–60,
duration seconds 3–120; lyrics <=3000; direction <=1000; locked boolean.
Up to 30 sections, total <=600 seconds, at least one section.

Track: `{id,name,gainDb,pan,muted,solo}`. name 1–60; gainDb -60..6;
pan -1..1; booleans; up to 12 tracks (zero allowed).

Clip: `{id,trackId,sectionId,assetId,offset,sourceOffset,duration,loop,gainDb}`.
UUID IDs, referenced section and track must exist; gainDb -60..6; nonnegative
offset/sourceOffset; duration >0 and <=600. Offset plus duration <= section
duration (epsilon 0.001). Source bounds verified by audio layer. Up to 256 clips.
All numeric values finite; unknown fields rejected. At most 128 referenced assets.

Section positions are the ordered prefix sum of durations. Tempo/key guide new
music; changing them never silently time-stretches or retunes existing audio.
Locked sections prevent content, duration and clip mutations; explicit unlocking
is required. Reordering the whole section is allowed. User-directed track mixing
is separate from section locking. No autogenerated audio plays automatically.

## Host and HTTP contract

`song_builder.init(app,current_user, data_dir=None, url_prefix='/song-builder', return_url='/noise-lab/')`
registers a default-off `SONG_BUILDER_ENABLED` blueprint. Authenticated host user
dict supplies `id`; fail closed. Each mutating request needs account-bound token
from page meta `song-builder-csrf` in `X-Song-Builder-CSRF`. Session/origin checks
and private no-store audio. HTML passes `builder_base_url`, `builder_assets_url`,
`builder_csrf`, `return_url`. Static blueprint name `song_builder`.

- GET `/api/capabilities`: `{schemaVersion:1,generation:{configured,provider,model,maxSeconds,unitPriceUsd},storage:{...},limits:{...}}`.
- GET `/api/projects`: `{projects:[{id,title,revision,updatedAt}]}`.
- POST `/api/projects` body `{project}`: returns `{project,revision,assets:[]}` 201.
- GET `/api/projects/<id>`: `{project,revision,assets:[Asset]}`.
- PUT `/api/projects/<id>` body `{project,expectedRevision}`: same response;
  stale save 409. Validate referenced asset ownership. Server enforces existing
  locks for section content and clips; explicit unlock alone precedes editing.
- DELETE `/api/projects/<id>` body `{expectedRevision}` removes owned project;
  audio shared by other projects is retained; unused owned assets can be removed.
- POST `/api/assets` multipart `file`: bounded PCM WAV upload; returns `{asset}`.
- GET `/api/assets/<id>/audio`: owned bytes, no public file path.
- Asset `{id,name,mime,size,duration,url}`; duration nullable for generated MP3,
  frontend decodes actual duration before creating clips. URL is module-relative
  full path generated by backend, not arbitrary client input.
- GET `/api/jobs?projectId=<id>`: `{jobs:[Job]}` owned project's recent jobs.
- POST `/api/jobs`: `{requestId,kind:'generate',projectId,sectionId,expectedRevision,prompt}`.
  Returns `{job}` 202; requestId idempotent per account, rejects changed payload.
  Optional separation kind uses `{requestId,kind:'separate',projectId,assetId,expectedRevision}`.
- GET `/api/jobs/<id>`: `{job}` status queued/running/succeeded/failed/interrupted.
- Job `{id,requestId,projectId,sectionId?,assetId?,kind,status,asset?,assets?,error?,createdAt}`.
  Separation returns the original source `assetId` so acceptance can require
  the matching selected clip rather than replacing unrelated audio.
  Generation takes never overwrite accepted clips on the server; musician accepts
  in the editor. Generation is one target section, not guaranteed contextual
  regeneration. Independent existing clips stay unchanged.

API errors `{error:code,message:safeText}`. Malformed input 400, owner mismatch
404, CSRF403, unavailable provider503, conflict409, quota429. No raw provider
response, prompt, credential or filesystem path leaks. Calls explicitly initiated
by user, bounded, no automatic retries. Durable jobs and attempt limits persist
across restart; interrupted requests are never silently charged again.

Separate module-owned SQLite and private audio under explicit data_dir. No
changes to main app tables or public uploads. Backups must include DB and audio.
ElevenLabs optional behind SONG_BUILDER_MUSIC_ENABLED plus ELEVENLABS_API_KEY.
This task does not add or change OpenAI API calls. Do not touch live environments.

## Core JavaScript exports

`project.mjs`: `newProject(title?)`, `validateProject(value)` returns validated
deep clone or throws; `sectionStart(project,sectionId)`, `projectDuration(project)`;
`addSection(project,kind?)`, `updateSection(project,id,patch)`,
`moveSection(project,id,delta)`, `duplicateSection(project,id)`,
`removeSection(project,id)`, `addTrack(project,name?)`,
`updateTrack(project,id,patch)`, `removeTrack(project,id)`,
`addClip(project,clip)`, `removeClip(project,id)` return a new validated project.
`newId()` uses crypto UUID. ID optional on addClip, generated if omitted.

`audio.mjs`: `AudioEngine` with async `decode(assetId,arrayBuffer)` returning
`{duration,sampleRate,channels}`, `has(assetId)`, `waveform(assetId,bins=100)`
(Float32Array peaks), async `play(project,{from=0,onEnded}={})`, `stop()`,
`position()` (seconds), async `render(project,{trackId}={})` (PCM WAV Blob),
`dispose()`. Uses one WebAudio clock; local mixing, proper source offset/loop,
track gain/pan/mute/solo. Bound decoded memory and export memory for mobile.
Do not import host files or provider SDKs. Never interpret prompts as code.
Export helper `encodeWav(channels,sampleRate)` returns ArrayBuffer of PCM16 WAV.
Optional original deterministic demo asset helper produces actual synthetic
audio and is clearly labeled demo, not AI or user work.

## Portable project file

`.sbsong` JSON envelope `{format:'street-banker-song-project',version:1,project,
assets:[{id,name,mime,dataBase64}]}`. Actual audio embedded. Maximum file 100MiB;
decode all entries before uploads; strict schema/IDs/length/base64 validation.
Import creates a new project ID and remaps asset IDs through owned uploads. No
remote URLs, account IDs, secret config or provider job IDs in portable files.
WAV-normalize assets in browser before upload. Save conflicts retain local work.
Downloads use a prepared link for a second iPhone tap; never navigate on save.
